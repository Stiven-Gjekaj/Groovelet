# The palette of Groovelet

The wordmark, the banner, and the logo use these colours.
The README must use the same values in its badges.

## Colours

| Name     | Hex       | Where it is used                                        |
| -------- | --------- | ------------------------------------------------------- |
| Panel    | `#111111` | The background of the banner and the wordmark           |
| Panel 2  | `#1c1c1c` | The centre of the glow behind the banner                |
| Disc     | `#2a2a2a` | The pixel record                                        |
| Groove   | `#3a3a3a` | The grooves of the pixel record                         |
| Amber    | `#ffb347` | The first stop of the word gradient, the first badge    |
| Coral    | `#ff6b4a` | The G groove, the borders, the second stop of the word  |
| Rose     | `#fb7a86` | The third stop of the word gradient                     |
| Pink     | `#f472b6` | The sound bars, the last stop of the word               |
| Pale     | `#f5f1ec` | The spindle hole, the line under the name, the release  |
| Pale 2   | `#fde4ec` | A pale badge, for the licence                           |

The word gradient runs along the word.
It starts with Amber and ends with Pink.
The stops are at 0, 0.4, 0.72, and 1.
